Channels

Tick a row to connect it. Type the channel name as it appears in the address bar — goodgame.ru/name (a numeric stream id also works) or twitch.tv/name. Read-only, no login needed.

Text

Locked shows just the text by default. Unlocked, moving the pointer over the window brings the backdrop up so you can see its edges to move and resize it.

Exact colours match the Twitch site exactly. Some users pick very dark colours — keep the black outline on so they stay readable over a game.

Badges

Twitch badge artwork is fetched per channel, so subscriber tiers and bits show their real icons. GoodGame does not publish badge images — those stay as text labels.
